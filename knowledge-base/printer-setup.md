# Printer Setup and Troubleshooting

## Adding a Network Printer

### Windows

1. Open Settings then Bluetooth and Devices then Printers and Scanners
2. Click **Add device**
3. Select your floor printer from the list (for example FL3-PrinterA)
4. If not listed, click **Add manually** and enter the printer path from the table below
5. The driver should install automatically
6. Print a test page to verify

### Mac

1. Open System Preferences then Printers and Scanners
2. Click the **+** button
3. Select the printer from the list
4. Click **Add**
5. Print a test page

## Common Issues

### Print Job Stuck in Queue

1. Open Printers and Scanners settings
2. Click on the printer
3. Click Open print queue
4. Right-click the stuck job and select Cancel
5. Try printing again

### Paper Jam

1. Open the printer front panel
2. Gently pull out any jammed paper in the direction of paper flow
3. Check the paper tray for misaligned sheets
4. Close the panel and wait for the printer to reset
5. If the Paper Jam error persists, check the rear access panel

### Printer Offline

1. Check the printer is powered on and shows Ready on its display
2. Verify network cable is connected (Ethernet light should be solid green)
3. On your computer, go to Printers and Scanners
4. Right-click the printer then Set as default printer
5. Right-click again then See what is printing then Printer menu then Uncheck Use Printer Offline

### Cannot Find the Printer

- Make sure you are connected to Corp-Secure Wi-Fi
- Verify you are searching for the correct floor printer
- Try adding manually using the printer path from the table above
- Contact IT if you need access to a printer on a different floor
