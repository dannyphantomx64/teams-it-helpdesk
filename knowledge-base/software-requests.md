# Software Installation Requests

## How to Request Software

1. Open the **Company Portal** app on your computer
2. Browse the available software catalog
3. If the software you need is listed, click **Install**
4. If it is not listed, submit a request:
   - Go to the IT Service Portal at https://it.company.com/request
   - Select **Software Request**
   - Fill in the software name, version, and business justification
   - Your manager will receive an approval request
   - Once approved, IT will make it available within 2 business days

## Policies

- All software must be installed through Company Portal or the IT Service Portal
- Do not download software from the internet directly
- Unauthorized software will be flagged and may be removed
- Free and open-source software still requires IT approval for security review
- License costs for approved software are charged to your department

## Common Issues

- **Installation failed**: Restart your computer and try again. If it persists, contact IT.
- **Access denied**: You may not have admin rights. Submit an IT request for installation.
- **Software not in catalog**: Submit a new software request through the IT Service Portal.
