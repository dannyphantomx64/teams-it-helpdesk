# Wi-Fi and Network Guide

## Connecting to Company Wi-Fi

### Corporate Network (Corp-Secure)

1. Select **Corp-Secure** from available Wi-Fi networks
2. Authentication type: WPA2-Enterprise
3. Enter your company email as the username
4. Enter your company password
5. Accept the certificate prompt if shown
6. You should connect automatically in the future

### Guest Network (Corp-Guest)

For visitors and personal devices:

1. Connect to **Corp-Guest**
2. Open a browser and a captive portal will appear
3. Enter the guest access code (ask reception)
4. Accept the terms of use
5. Guest access expires after 24 hours

## Troubleshooting

### Cannot Connect to Corp-Secure

1. Forget the network and reconnect:
   - Windows: Settings then Network then Wi-Fi then Manage known networks then Corp-Secure then Forget
   - Mac: System Preferences then Network then Wi-Fi then Advanced then Remove Corp-Secure
2. Restart your Wi-Fi adapter
3. Verify your password has not expired
4. Try connecting to Corp-Guest as a temporary workaround

### Slow Network Speeds

- Move closer to an access point
- Disconnect from VPN if accessing local resources
- Check if large downloads are running in the background
- Try restarting your device
- Report persistent slow areas to IT so we can check coverage

### No Internet After Connecting

1. Open a browser and check for a captive portal redirect
2. Run network diagnostics:
   - Windows: Right-click Wi-Fi icon then Troubleshoot problems
   - Mac: Option+click Wi-Fi icon then Open Wireless Diagnostics
3. Try flushing DNS: Open Command Prompt and run ipconfig /flushdns

## Network Policies

- Company-issued devices must use Corp-Secure
- Personal devices should use Corp-Guest
- Streaming services are deprioritized on the corporate network
- All network activity is monitored per company IT policy
